## 📌 Overview
The password for the next level is stored in a file called readme located in the home directory.  
Use this password to log into bandit1 using SSH. Whenever you find a password for a level,  
use SSH (on port 2220) to log into that level and continue the game.

### Objective
  Learn how to list file and read content of file 

### Command used
  1. `ls` : list file
  2. `cat [file]` : read content of file

### Apply to situation
  When `ls` are used there show a file called *readme*. And we know that it stored password for next level.  
  Lets use `cat readme` to get the password
